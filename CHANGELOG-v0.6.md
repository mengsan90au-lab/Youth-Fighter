# Youth Fighter v0.6.0

Upgraded Residential Ward from generic box houses to an original illustrated Khmer-inspired building kit with terracotta curved roofs, timber facades, sandstone steps, an elder’s home, clinic, family homes, local shop, food stall and roofed well. Added matching paving, banana plants, flowers and hanging lanterns; refined residential depth sorting, signs and player occlusion fading.

Preserved the old district/road/gateway identities, five original collision rectangles, NPC positions and parcel mission. Added two service footprints, a solid well/bench, a goods keeper, healer and well keeper using the existing validated shop/rest rules. Mini-maps reflect the new landmarks and courtyard surfaces. Save schema stays v4.

Added a physical multi-gate Residential Ward walking guide and fixed click-paths passing through unrelated return gates. Existing combat, laws, missions, atlas artwork, LAN and separate solo testing remain. Nine map images and the new sprite sheet are embedded offline and served through the strict host allowlist.

Validation: 63 automated tests, asset alpha/cell/hash verification, original-vs-upgraded real native Canvas game renders reviewed, and ZIP/source comparison. Real browser UI acceptance, FPS and Unity visuals remain unverified; no new Unity implementation is claimed.
