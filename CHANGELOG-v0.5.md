# Youth Fighter v0.5.0

Added five playable Sovann City wards to the browser game, with original isometric buildings, market awnings/stalls, scenery, NPCs and lawful patrol guards. Added reciprocal district entrances, an Old Sovann Square entrance and a South Gate ↔ Bamboo Grove route; existing gates and IDs remain.

Added functional NPC conversations, shops, inventory/equipment, food/herbs, banking/storage, bounded blacksmith upgrades/repairs, inns/meditation, eight one-time city missions and consensual sparring. Services validate range, ownership, stock, prices, balance and objective state under the shared host rules. Skill paths retain their existing restrictions.

Added a city-district overview, district-local NPC finder/live mini-maps, blocked canal water/bridges, guard obstacle navigation, beginner HUD controls and save v4 with old-save migration. Preserved the approved nine atlas backgrounds and extended the optional solo test circuit to 127 locations.

Validation: 59 automated tests pass, including real network city trade/mission checks, ten-client room checks, physical travel, water/building collision, NPC interactions, save state, crime and simulated presentation at 1280×720, 1440×900 and 1920×1080. Live browser rendering and Unity Play mode remain unverified. New city content is browser-only; the native project is preserved, not claimed updated with five native scenes.
