# Play Youth Fighter combat preview

Read **COMBAT-START-HERE.md** for the new combat controls, discovery challenge, Focus and current validation limits. Choose among five schools and earn lessons from Dara. The keys below are defaults; K opens key settings. Ordinary 1/2/3 remain; Q guards, Space dodges, 4 uses a discovered technique, 5/V use the separate standard/enhanced ultimate.

1. Keep your previous game ZIP. Extract this **whole new ZIP** into a new folder.
2. Double-click **PLAY-YOUTH-FIGHTER.cmd**. If HTML normally opens in VS Code, use the launcher, or open Chrome/Edge, press Ctrl+O and choose **Youth-Fighter.html**.
3. Choose a school, then click **Enter the basin**. Click open ground to move; WASD/arrows do not walk. **Normal Walk** is the default.
4. Use the **Move** selector near the mini-map to choose Walk, Slow or Run. Press **I → Walk to Master Dara** for the first school quest; **K** changes skill and panel bindings.
5. Press **L** for Motion Studio. Try **Three-style comparison**, eight-direction views, five-position journeys or the four environment clips. Choose a Style to change the reviewed animation.
6. For the distance test, choose **Coordinate movement lab**, select a style and click **Start (0,0) to (9,5) metre test**. Restart for each style. Your real fighter stays in place.
7. Press **G** for 30/60/120/Auto and **Show measured performance**. Start with 60 if your display/performance is uncertain. The selected target is not a guarantee of actual FPS.

**Combat footwork** means the game temporarily keeps the old combat movement speed while fighting, wanted, cooling down or close to hostile monsters. Exploration styles resume when the condition ends.

Other controls: E near NPCs; 1/2/3 attack; R tonic; F arrest; H appearance; I schools and lessons; J journal; M world map; Inventory for owned items. Map viewing never teleports you. Use actual exits or the Market/Residential walking buttons. Optional solo testing can unlock all map interfaces/test areas. Normal mode still distinguishes implemented areas from future locations.

LAN hosting: install a compatible Node.js runtime, then run **Start-Youth-Fighter.cmd**. For solo play the standalone HTML needs no server or Node. This is the updated browser game; Native Unity is unavailable until its missing project metadata is restored.

Keep the same browser and its storage. Changing file folders or server addresses may affect access to the old browser origin's save, so retain your old folder until your character is confirmed. Save v6 accepts v2/v3/v4/v5/v6; school records, learned skills and known discoveries persist while Focus and action/combo/challenge opportunities reset. LAN progress is still host-session-only.

Read **MOVEMENT-STYLES.md** for calibration, measurements and visual limits. Precise foot locking, perfect sprite identity and rig-authored braking remain unfinished; real browser 120 FPS has not been measured here.
