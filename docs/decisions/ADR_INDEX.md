# Architecture Decision Records

Status: Index for future decisions.

## Purpose
This index tracks high-impact engineering decisions that affect gameplay architecture, world design, migration paths, and platform boundaries.

## Proposed ADR set
- ADR-001: Keep the browser prototype as the active verified runtime while the project matures.
- ADR-002: Maintain authoritative server-side simulation and explicit client/server boundaries.
- ADR-003: Treat map data as structured world content, not ad hoc script logic.
- ADR-004: Keep save compatibility versioned and validated.
- ADR-005: Delay Unity migration until a real Unity project and build pipeline are available.

## Update process
Each ADR should include:
- status
- context
- decision
- consequences
- risks
- validation evidence
