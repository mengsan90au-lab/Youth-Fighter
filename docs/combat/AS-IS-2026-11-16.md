## Actual trace

`game.js: strike/send` sends `{type:'attack',skill:0..2,pvp}` to either `YF.command` locally or WebSocket. `server.js: handle` parses bounded JSON frames, rate limits to 90 messages/second, then calls that same command. `world.js: command` coerces attack indices (`Number(a.skill)||0`), so malformed skill strings can become a basic attack. `save-contract.js: validateCommand` has no runtime consumer. Movement accepts coerced values; unknown commands fall through.

`world.js: attack` selects `skillsFor(path)`, checks cooldown/energy/selected target/range/map/jail, checks peaceful permission for the primary target, spends energy and starts cooldown, then immediately subtracts HP. Area skills search same-map entities by radial distance. No wall ray, directional geometry or authoritative startup/active/recovery exists. Secondary victims have narrower kind filtering but no independent eligibility gate. `city.hit` advances training and wears equipment per victim. `city.duel` supplies nonlethal sparring; assault/murder, wolf/bandit rewards, arrest and city return are in world.js. Dead NPCs respawn in step. A defeated player returns immediately with full HP, making per-action victim deduplication essential for future multihits.

`world.js: event` appends bounded numbered text events; `game.js: processEvents` deduplicates by increasing event ID and produces floats, tones and logs. `hero-animation.js: pose` derives visual phases solely from `lastStrike`/numeric `strike`. `hero-motion-render.js: draw` delegates to that legacy renderer for 0.65 seconds. Neither owns hits. `hero-locomotion.js` and `performance.js: Positions` retain presentation copies; `game.js: frameLoop` steps the solo world through a default 60 Hz Clock and draws separately. Canvas projection is isometric. No 3D gameplay proof.

`movement-styles.js: tick/combatLocked` owns calibrated exploration and the existing 5-unit/second combat override. `navigation.js: findPath` and `world.js: move` use `map-catalog.js: blocked` (bounds/buildings/decor/water/bridges); swept movement uses short collision increments. `enterMap/useExit` clear navigation and target, with a travel lock. `city-system.js: command/tick` owns inventory, services, quests, equipment, durability, rest and reciprocal sparring. `city-data.js` provides wraps restricted to fist and reed-spear to spear; path switching currently leaves incompatible equipped items in the slot (attack bonus is suppressed). Spear rendering is already path based; it does not require buying a spear for basic viability.

`progression.js: snapshot/restore` writes version 4 and accepts 2/3/4, sanitizes city state, validates map position, clamps legacy cooldowns to 9, and defaults v2 to Sovann City. It currently has no transient combat state. `game.js: saveSolo/connect` keeps solo saves local: welcome replaces the local world and never uploads progression. `server.js` uses 20 Hz simulation, nominal 10 Hz snapshots, ten sockets, 4096-byte messages and session-only player state; disconnect deletes the player. This is LAN infrastructure only.

Skills: fist = Naga fist (18/2.5/0/.5), Elbow surge (32/3/22/3), Naga awakening (42/4.5/45/9); spear = Spear thrust (16/3.6/0/.65), Serpent sweep (29/4/22/3), Naga tempest (40/5/45/9), values damage/range/energy/cooldown seconds. All are ordinary energy skills. Energy regeneration is 12/second, maximum 100. The UI's third-skill ultimate class does not implement a separate ultimate resource.
